## 0.0.3

### Patch Changes

- 74fa2b0: fix: sentinel auto-rearm — when the bun curl installer clobbers the wrapper (marker missing / integrity mismatch), the sentinel now restores the wrapper from the package source (atomic .new + mv) and re-pins bun-real to the fleet-pinned 1.3.14 build (sha 37141662ebed915a, verified against the release SHASUMS256.txt and the pinned binary sha) instead of only alerting; it exits 0 only after the static chain and the functional canary pass, and fails closed into the alert path when the rearm cannot be verified. The download is arch-derived (the recorded sha is the aarch64 build the fleet installer installs) and cached in the guard dir's pinned/ store; pin constants are config-overridable. battery section 17 + hermetic smoke regress the rearm on a temp-dir copy of the bin layout; the marker-preserving-tamper, unscoped-wrapper and wrapper-missing fixtures were made rearm-aware (heal vs fail-closed) and hermetic so the battery never mutates the live install. Row 7112181b.
- e2e4d53: fix: sentinel.sh VERSION now DERIVES from the package.json beside the script (script-relative, POSIX-only grep/sed — no bun/node/jq dependency at read time) instead of a static constant. The manual `VERSION="0.0.2"` was the versioning runtime-export drift class (b335a922) that failed wave PR 791: the wave bumped package.json to 0.0.3 while the packed sentinel still carried 0.0.2, so the prepack smoke (which asserts `--version` == package.json version) and the publish guard failed. A standalone copy without a package.json beside it now fails closed on the version surface (--version exits non-zero with a clear message) rather than silently reporting a possibly-stale version; the main probe is unaffected (it does not depend on VERSION, and the fleet install at ~/.hasna/test-guard is such a copy). smoke.sh gains a red-before/green-after regression on a temp-dir copy with a deliberately different version, plus the no-package.json fail-closed assertion. Rows 1804474f / b335a922.
- publish-all-test-guard: release-review remediation for the 0.0.3 ship (adversarial review, 2026-08-22). (a) `--version` now resolves the package.json through the bin SYMLINK chain (portable readlink loop): a package-manager global install invokes the bin via ~/.bun/bin/test-guard → node_modules/@hasna/test-guard/sentinel.sh, and the pre-fix dirname "$0" reported VERSION unavailable on the installed bin; standalone-copy fail-closed behavior is unchanged, and smoke.sh regresses the symlink case. (b) packed content no longer carries internal-infra references (station names, the retired cloud-runtime env path); the no-cloud regression now scans the COMPLETE shipped file set — all five package.json "files" entries — for the cloud pattern and stationN names. (c) battery section 15 is fully hermetic: every sentinel invocation drives temp copies of the wrapper and bun-real plus a temp guard dir, so a healthy run no longer writes the live guard-dir log and a clobber can no longer trigger an auto-rearm of the live install mid-battery. The wrapper gains a TEST-ONLY `HASNA_TEST_GUARD_REAL` override (same seam class as `HASNA_TEST_GUARD_DIR`, production default unchanged) so even the canary probe execs the temp real-bun copy rather than the live binary; smoke.sh regresses the override. (d) battery sections 7/8 gained the run_scoped bus fallback: their direct systemd-run --user --scope calls failed with "Failed to connect to bus: No medium found" from headless shells (no XDG_RUNTIME_DIR/DBUS_SESSION_BUS_ADDRESS), failing the battery 2/60 in background contexts; run_scoped mirrors the wrapper's own prepare_systemd_user_manager seam (fall back to the /run/user/<uid> bus when the session bus is unreachable and the directory exists and is ours).

## 0.0.2

### Patch Changes

- 4cd9ab4: Add --version and --help flags to sentinel.sh (task a6fc52c7). The flags short-circuit before any check, so a flag can never be mistaken for the positional bun-path argument again (this exact misparse posted two false [ALERT]s to #incidents on 2026-08-20). test/smoke.sh regresses both flags and asserts --version matches package.json.
- 8cb1eab: First release from the hasna/apps monorepo. The SC-00062 bun-test concurrency guard (sentinel, bun-wrapper, battery) previously lived only machine-local at `~/.hasna/test-guard` and could not ship as a PR. This package home imports the scripts byte-faithfully with one deliberate deviation: the sentinel no longer sources the retired `$HOME/.hasna/cloud/hasna-cloud-env.sh` runtime config (forbidden by the no-cloud guard for public packages), and the hermetic smoke is wired as the package test with a regression asserting the retired config is never sourced. `0.0.1` is the first release under the monorepo.
