# AGENTS.md

`connect-toggl-track` — Toggl Track API v9 connector with API token (Basic) auth.

- Package: `@hasna/connect-toggl-track`
- CLI: `connect-toggl-track`
- Auth env: `TOGGL_TRACK_API_TOKEN`
- Base URL: `https://api.track.toggl.com/api/v9`

Run `bun test` and `bun run typecheck` in this directory before publishing.
