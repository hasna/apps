# connect-googleads

Google Ads API connector CLI - Campaigns, ad groups, ads, keywords, and reporting

## Installation

```bash
bun install -g @hasna/connect-googleads
```

## Quick Start

```bash
# Set your API key
connect-googleads config set-key YOUR_API_KEY

# Or use environment variable
export GOOGLE_ADS_DEVELOPER_TOKEN=YOUR_API_KEY
```

## Development

```bash
# Install dependencies
bun install

# Run CLI in development
bun run dev

# Build
bun run build

# Type check
bun run typecheck
```
