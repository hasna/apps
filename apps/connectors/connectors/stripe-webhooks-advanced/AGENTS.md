# AGENTS.md

Stripe Webhooks Advanced connector for `@hasna/connectors` monorepo.

## Overview

Focused Stripe API connector: webhook endpoints, events, local signature verification.

## Security

- No hardcoded secrets
- `.env.example` has placeholders only
- `@hasna` namespace

## CLI

`connect-stripe-webhooks-advanced`
