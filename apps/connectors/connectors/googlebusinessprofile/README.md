# connect-googlebusinessprofile

Google Business Profile API connector with multi-profile support

## Installation

```bash
bun install -g @hasna/connect-googlebusinessprofile
```

## Quick Start

```bash
# Set your API key
connect-googlebusinessprofile config set-key YOUR_API_KEY

# Or use environment variable
export GOOGLE_BUSINESS_PROFILE_API_KEY=YOUR_API_KEY
```

## Development

```bash
# Install dependencies
bun install

# Run CLI in development
bun run dev

# Build
bun run build

# Type check
bun run typecheck
```
