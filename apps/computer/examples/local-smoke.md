# Local Smoke

These commands are safe local package checks. They do not control the desktop, open external sites, or require provider credentials.

```sh
computer --version
computer-mcp --help
computer-serve --help
computer storage status --json
```

For live desktop validation, use the P8 machine readiness gates first: route, GUI/session state, screen credentials, accessibility and screen-recording permissions, runtime lease acquisition, cleanup plan, and Todo artifact recording.
